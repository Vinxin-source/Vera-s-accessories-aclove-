# Vera's Accessories Aclove — Online Store

Self-serve e-commerce for China procurement & accessories.

## Features
- Empty catalog (owner adds products)
- Admin: products (photo from phone), settings (logo, bank, WhatsApp), orders
- Cart, checkout, bank transfer details on checkout
- Contact + Instagram
- Mobile-first design

## Admin
- Login: `/admin/login` — default password `vera2026`
- Products: `/admin/products`
- Settings: `/admin/settings`
- Orders: `/admin/orders`

## Deploy
Push to GitHub → import on Vercel → Deploy.
